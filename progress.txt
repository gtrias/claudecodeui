## Learnings

### Established Patterns (from previous conversions)
- Always import React types: `import React, { useState, FC } from 'react';`
- Use `React.FC<Props>` for functional components
- Create interfaces for all props: `interface ComponentProps { ... }`
- Type all event handlers: `ChangeEvent<HTMLInputElement>`, `FormEvent<HTMLFormElement>`
- Use proper generic types: `useState<Type>(initial)`
- Export types for reusability
- Delete old JSX files after successful conversion

### Common Type Patterns
